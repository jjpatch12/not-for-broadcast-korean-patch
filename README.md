# Not For Broadcast 한국어 패치

`v0.9.0`은 **Not For Broadcast 빌드 `2024.10.04b.TL` 전용 비공식 한국어 패치 최종 배포본**입니다. 메뉴와 UI, 대사·자막, 확정된 정적 이미지 문구를 한국어로 바꿉니다. 이 버전을 끝으로 패치 제작을 종료합니다.

## 설치

1. [Releases](https://github.com/jjpatch12/not-for-broadcast-korean-patch/releases)에서 `NotForBroadcast_KoreanPatch_v0.9.0.zip`을 받습니다.
2. ZIP 안의 파일을 `NotForBroadcast.exe`가 있는 게임 설치 폴더에 풉니다.
3. 게임을 종료한 상태에서 `한국어패치.bat`를 실행합니다.

설치기는 게임 빌드와 원본 파일 해시를 먼저 확인합니다. 지원 범위가 다르면 파일을 바꾸지 않고 중단합니다. 내부 델타와 설치 스크립트는 `.nfb-ko-data` 숨김 폴더에 들어 있습니다.

## 제거

게임 설치 폴더에서 명령 프롬프트를 열고 다음 중 하나를 실행합니다.

```bat
한국어패치.bat uninstall
```

```bat
한국어패치.bat 제거
```

설치 때 만든 `.nfb-ko-backup\0.9.0`의 검증된 백업으로 원본을 복원합니다.

## 최종 패치 범위

- UI 번역: 1,623행
- 대사 마스터: 62,898행
- 게임 주입 완료: 62,889행
- 원문 검수에서 제외한 행: 9행
- 정적 이미지 문구 적용: 171개 이미지 범위
- 이번 버전에서 추가한 정적 이미지: 63개, Unity 에셋 파일 15개
- 설치 대상: 이진 델타 75개와 보조 파일 1개

세부 집계와 검증 결과는 [PATCH_SCOPE.md](PATCH_SCOPE.md)에 적었습니다.

## 지원 조건

- 별도 한글 폰트 패키지는 포함하지 않습니다.
- 게임 빌드 `2024.10.04b.TL`에서만 설치할 수 있습니다.
- 위에 적은 범위를 이 패치의 최종 범위로 확정했으며 추가 업데이트는 계획하지 않습니다.

이 저장소에는 완전한 게임 파일을 올리지 않습니다. 릴리스 ZIP에는 사용자가 보유한 원본에서 한국어화 상태를 만드는 이진 델타와 설치 도구만 포함됩니다. 이 프로젝트는 NotGames 또는 게임 배급사와 무관한 팬 패치입니다.
