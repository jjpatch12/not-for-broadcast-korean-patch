# Not For Broadcast 한국어 패치

`v0.2.0-partial`은 **Not For Broadcast 빌드 `2024.10.04b.TL` 전용 비공식 한국어 패치**입니다. 메뉴와 UI, 대사·자막, 검수 완료된 정적 이미지 문구를 한국어로 바꿉니다. 이미지 한국어화는 아직 일부가 남아 있어 이 버전은 부분 완료 프리릴리스로 배포합니다.

## 설치

1. [Releases](https://github.com/jjpatch12/not-for-broadcast-korean-patch/releases)에서 `NotForBroadcast_KoreanPatch_v0.2.0-partial.zip`을 받습니다.
2. ZIP 안의 파일을 `NotForBroadcast.exe`가 있는 게임 설치 폴더에 풉니다.
3. 게임을 종료한 상태에서 `한국어패치.bat`를 실행합니다.

설치기는 게임 빌드와 원본 파일 해시를 먼저 확인합니다. 지원 범위가 다르면 파일을 바꾸지 않고 중단합니다. 내부 델타와 설치 스크립트는 `.nfb-ko-data` 숨김 폴더에 들어 있습니다.

## 제거

게임 설치 폴더에서 명령 프롬프트를 열고 다음 중 하나를 실행합니다.

```bat
한국어패치.bat uninstall
```

```bat
한국어패치.bat 제거
```

설치 때 만든 `.nfb-ko-backup\0.2.0-partial`의 검증된 백업으로 원본을 복원합니다.

## 현재 범위

- UI 번역: 1,623행
- 대사 마스터: 62,898행
- 게임 주입 완료: 62,889행
- 원문 검수에서 제외한 행: 9행
- 정적 이미지 문구 적용: 검토 목록 244개 중 171개 이미지 범위
- 이번 버전에서 추가한 정적 이미지: 63개, Unity 에셋 파일 15개
- 설치 대상: 이진 델타 75개와 보조 파일 1개

남은 범위와 집계 기준은 [PATCH_SCOPE.md](PATCH_SCOPE.md)에 적었습니다.

## 확인된 제한

- 등록된 비보류 정적 이미지 약 65개가 아직 남아 있습니다.
- 영상 프레임에 박힌 영문과 등록되지 않은 일부 배경 문구는 전부 번역되지 않았습니다.
- 모든 분기와 DLC를 포함한 전체 플레이스루 검증은 완료하지 않았습니다.
- 별도 한글 폰트 패키지는 포함하지 않습니다.
- 다른 게임 빌드에서는 설치할 수 없습니다.

이 저장소에는 완전한 게임 파일을 올리지 않습니다. 릴리스 ZIP에는 사용자가 보유한 원본에서 한국어화 상태를 만드는 이진 델타와 설치 도구만 포함됩니다. 이 프로젝트는 NotGames 또는 게임 배급사와 무관한 팬 패치입니다.
